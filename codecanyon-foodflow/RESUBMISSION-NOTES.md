## Note on the rename

The product is submitted as **FoodFlow**. The packaging script stamps this name onto `.env.example`'s `APP_NAME` and each Flutter app's display name (`android:label` / `CFBundleDisplayName`) in the **staged copy only** — the original source repository's own branding is untouched by this process.
